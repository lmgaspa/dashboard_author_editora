## GOAL

Create a backend API for the admin/financial dashboard to list and inspect Pix webhook events from `payment_webhook_events` and send the data in a clean JSON DTO to the frontend.

We want:

- A REST endpoint like:
  - `GET /api/v1/admin/payments/pix-webhooks`
  - `GET /api/v1/admin/payments/pix-webhooks/{id}`

The endpoint must:

- Be read-only;
- Be accessible only to authenticated/admin users (use the existing security configuration pattern from the project);
- Support basic filters and pagination for the list endpoint.

---

We need to extract from `payload_json` (JSONB) the first entry of the `pix` array, with at least:

- `txid` (string) → `payload_json->'pix'->0->>'txid'`
- `chave` (string)
- `valor` (string → but send as BigDecimal in the DTO)
- `horario` (ISO string → convert to OffsetDateTime)
- `nome_pagador` (string) → `gnExtras.pagador.nome`
- `cpf_pagador` (string) → `gnExtras.pagador.cpf`
- `end_to_end_id` (string) → `endToEndId`
- `orderRef` (nullable string) → `payload_json->>'orderRef'`

On the DTO we also want:

- `id`
- `eventType`
- `provider`
- `receivedAt` (OffsetDateTime)
- The extracted Pix fields above.

### 4. Create a Service:

**Name:** `PixWebhookEventService`

**Responsibilities:**
- Paginate and filter `payment_webhook_events` for `event_type LIKE 'pix.%'`.
- Parse `payload_json` using Jackson to extract the fields listed above.
- Map `PaymentWebhookEventEntity` → `PixWebhookEventDTO`.

**The service must have at least:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class PixWebhookEventService {
    private final PaymentWebhookEventRepository repository;
    private final ObjectMapper objectMapper;
    
    public Page<PixWebhookEventDTO> listPixWebhooks(int page, int size) {
        Pageable pageable = PageRequest.of(page, size);
        Page<PaymentWebhookEventEntity> entities = repository.findByEventTypeStartingWith("pix.", pageable);
        return entities.map(this::mapToDto);
    }
    
    public PixWebhookEventDTO getPixWebhookById(Long id) {
        PaymentWebhookEventEntity entity = repository.findById(id)
            .orElseThrow(() -> new EntityNotFoundException("Pix webhook event not found with id: " + id));
        return mapToDto(entity);
    }
    
    private PixWebhookEventDTO mapToDto(PaymentWebhookEventEntity entity) {
        try {
            JsonNode root = objectMapper.readTree(entity.getPayloadJson());
            JsonNode pixArray = root.get("pix");
            JsonNode firstPix = pixArray != null && pixArray.isArray() && pixArray.size() > 0 
                ? pixArray.get(0) 
                : null;
            
            JsonNode gnExtras = firstPix != null ? firstPix.get("gnExtras") : null;
            JsonNode pagador = gnExtras != null ? gnExtras.get("pagador") : null;
            
            String valorStr = firstPix != null && firstPix.has("valor") 
                ? firstPix.get("valor").asText() 
                : null;
            BigDecimal valor = valorStr != null && !valorStr.isEmpty() 
                ? new BigDecimal(valorStr) 
                : null;
            
            String horarioStr = firstPix != null && firstPix.has("horario") 
                ? firstPix.get("horario").asText() 
                : null;
            OffsetDateTime horarioPix = horarioStr != null 
                ? OffsetDateTime.parse(horarioStr) 
                : null;
            
            return PixWebhookEventDTO.builder()
                .id(entity.getId())
                .eventType(entity.getEventType())
                .provider(entity.getProvider())
                .receivedAt(entity.getReceivedAt())
                .txid(firstPix != null && firstPix.has("txid") ? firstPix.get("txid").asText() : null)
                .chave(firstPix != null && firstPix.has("chave") ? firstPix.get("chave").asText() : null)
                .valor(valor)
                .horarioPix(horarioPix)
                .nomePagador(pagador != null && pagador.has("nome") ? pagador.get("nome").asText() : null)
                .cpfPagador(pagador != null && pagador.has("cpf") ? pagador.get("cpf").asText() : null)
                .endToEndId(firstPix != null && firstPix.has("endToEndId") ? firstPix.get("endToEndId").asText() : null)
                .orderRef(root.has("orderRef") && !root.get("orderRef").isNull() ? root.get("orderRef").asText() : null)
                .build();
        } catch (Exception e) {
            log.error("Error parsing payload_json for webhook event id: {}", entity.getId(), e);
            // Return DTO with basic fields only
            return PixWebhookEventDTO.builder()
                .id(entity.getId())
                .eventType(entity.getEventType())
                .provider(entity.getProvider())
                .receivedAt(entity.getReceivedAt())
                .build();
        }
    }
}
```

**Implement the JSON parsing in a private mapper function** using `ObjectMapper.readTree(entity.getPayloadJson())` and safely navigating:

```java

JsonNode pixNode = root.get("pix") != null && root.get("pix").isArray() && root.get("pix").size() > 0 
    ? root.get("pix").get(0) 
    : null;
JsonNode gnExtras = pixNode != null ? pixNode.get("gnExtras") : null;
JsonNode pagador = gnExtras != null ? gnExtras.get("pagador") : null;
```

### 5. Create a REST Controller:

```java
@RestController
@RequestMapping("/api/v1/admin/payments/pix-webhooks")

public class PixWebhookEventController {
    private final PixWebhookEventService service;
    
    @GetMapping
    @PreAuthorize("hasRole('ADMIN')")

        PixWebhookEventDTO result = service.getPixWebhookById(id);
        return ResponseEntity.ok(result);
    }
}
```
